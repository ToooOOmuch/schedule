# 週間スケジュール

CCNA・ジム・雀魂の予定を週ごとに立てて、5段階の達成チェックで進み具合を記録する時間割アプリです。

- 公開中のアプリ（claude.ai）: https://claude.ai/artifact/9WZu7Seuz58AzELEsau16a

## できること

- 10/26からの週ごとの時間割（今週・来週・再来週の作成、前の週のコピー）
- Outlookのような操作（ドラッグで移動・伸縮、コピー＆貼り付け、元に戻す）
- 予定ごとのメモと、5段階の達成チェック
- 週の達成度と、目標（CCNA合格・魂天Lv1→Lv3・かっこいい体）の達成予定日

## ファイル構成

| パス | 内容 |
|---|---|
| `index.html` | claude.ai で公開中のページそのもの（予定データ入り）。ブラウザで開けばそのまま動きます |
| `src/page.tpl.html` | ページの本体（見た目と動き）。`__DATA__` の位置に予定データが入ります |
| `src/plan-data.json` | 予定データ（基本の予定、週ごとの予定、目標） |
| `build.py` | `src/` から `dist/weekly-plan.html` を作るスクリプト |

## 作り直し方

```sh
python3 build.py
```

`dist/weekly-plan.html` ができます。これを claude.ai のアプリに公開し直すと、内容が反映されます。

## 保存について

- claude.ai 上のアプリでは、「保存する」を押すとページ自体が更新されます
- この `index.html` をブラウザで直接開いた場合は保存できません。変更はそのブラウザに一時的に残るだけです
- アプリ上で予定を保存しても、このリポジトリには自動では反映されません。必要なときにアプリの最新版を取り込んでください
